# РемТех — информационная система сервисного центра

Учебный проект: настольное приложение для учёта заявок на ремонт бытовой
техники. Реализовано на Python 3.10 с интерфейсом tkinter и базой данных
SQLite; внешние зависимости отсутствуют.

## Возможности

- журнал заявок с поиском по номеру, клиенту, телефону, технике и описанию;
- фильтрация по статусу и мастеру, подсветка просроченных заявок;
- справочники клиентов, оборудования и мастеров;
- назначение мастера, изменение статуса по разрешённой цепочке;
- учёт выполненных работ и автоматический расчёт стоимости;
- история изменений статусов;
- отчёты: распределение заявок, загрузка мастеров, выручка за период;
- экспорт журнала заявок в CSV (UTF-8 с BOM, разделитель «;»).

## Запуск

```bash
python3 run.py
```

При первом запуске создаётся файл `remteh.db` и заполняется демонстрационными
данными. Чтобы указать другой файл базы:

```bash
python3 run.py --db /path/to/remteh.db
```

Открыть сразу нужную вкладку: `--tab 0..4` (заявки, клиенты, оборудование,
мастера, отчёты).

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

54 теста (46 модульных и 8 сценарных) проверяют модели, репозитории, бизнес-правила, экспорт и сквозные сценарии обслуживания.

## Структура

```
remteh/
  models.py        доменные модели, статусы, приоритеты
  db.py            схема SQLite и подключение
  repositories.py  SQL-запросы и преобразование строк
  service.py       бизнес-правила и отчёты
  export.py        экспорт в CSV
  seed.py          демонстрационные данные
  gui.py           интерфейс tkinter
tests/             модульные и сценарные тесты unittest
run.py             точка входа
```

## Правила предметной области

Статусы заявки: новая → принята → в работе → выполнена → закрыта. Допускаются
также переходы в «ожидает детали» и «отменена». Завершить заявку нельзя без
хотя бы одной выполненной работы; стоимость заявки равна сумме стоимости работ.
